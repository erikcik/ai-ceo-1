# evidence/level-4/citation-audit.md -- generated, do not hand-edit

Generated by `evidence/level-4/make-level4-checks.sh`. One row per substantive sentence in
the body of the final `REPORT.md` -- **every** sentence, not only the cited ones, so a
sentence cannot escape the audit by carrying no citation. The opening words of each row are
*extracted from `REPORT.md` at the line given*, not retyped.

The verdict column is computed, not asserted. For a row citing `key#Qn`, PASS means the
canonical check `tr -s '[:space:]' ' ' < sources/raw/<key>.txt | grep -F -c "<quote>"`
returned >= 1 (transcript: `verify.txt` section 1) **and** the report sentence carries the
inline `[key]` -- or, where it does not, the row says `back-reference` and the note names
the line that does. For a row resting on an absence check `A<n>`, PASS means that check's
residual is 0 (transcript: `verify.txt` section 4).

There are no `UNCHECKED` rows.
